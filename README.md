**Professional Cloud Web Application**

A scalable, production-ready web application designed using modern cloud architecture and industry-standard development practices. The application features a responsive HTML ,CSS and JavaScript  frontend, Spring Boot backend, secure REST APIs, and a managed relational database. It is deployed on cloud infrastructure with load balancing, auto-scaling, CDN-based content delivery, secure networking, authentication, monitoring, and automated CI/CD pipelines. Infrastructure is provisioned using Terraform to ensure consistency, scalability, and easy deployment across environments.

**Tech Stack:** React.js, FastAPI, Python, REST APIs, SQL, AWS/GCP, Docker, Terraform, CI/CD, GitHub Actions.
